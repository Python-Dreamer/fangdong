🔒 隐私声明

最后更新：2026年9月16日

一、我们收集什么信息

房东管家系统收集以下信息用于租赁管理：

  • 账户信息：您的登录邮箱
  • 租户基本信息：姓名、手机号、国籍、性别
  • 身份证明信息：身份证号码（用于身份核验，并自动识别性别和年龄）
  • 同住人信息：共同居住人员的姓名、手机号、国籍、性别、身份证号码
  • 租赁信息：楼栋/房间信息、租金金额、押金、合同期限、付款方式
  • 水电信息：水表、电表抄表读数及用量、水电费记录
  • 紧急联系人：紧急联系人姓名和联系方式
  • 合同资料：租赁合同照片和文件（PDF/Word格式）
  • 提醒设置：您自行配置的通知邮箱、微信推送标识

二、为什么收集这些信息

我们收集这些信息的目的仅限于：

  • 管理房屋租赁关系（房间、租户、合同）
  • 计算租金、水电费，发送缴费提醒
  • 合同到期提醒
  • 身份核验（身份证号码用于核验及自动识别性别、年龄）
  • 紧急情况联系（紧急联系人）
  • 向您本人发送缴费、生日等提醒通知

我们不会向任何第三方出售您的个人信息，也不会将您的信息用于上述目的之外的任何用途。

三、数据存储在哪里

您的全部数据存储在 中国大陆境内的云服务器（阿里云，北京节点）的自建数据库中，数据全部存储在境内，不出境，并具有以下安全措施：

  • 加密传输：全站使用 HTTPS 加密传输数据
  • 访问控制：必须登录后才能访问，系统通过用户认证和权限控制确保数据安全
  • 数据隔离：不同房东的数据按账号完全隔离，互不可见
  • 本地缓存：系统会在您的浏览器本地自动保存一份数据缓存用于备份，您可随时清除浏览器数据
  • 数据导出：您可随时通过系统内的"导出Excel"功能将全部数据导出到本地保存

四、数据安全保护

我们采取以下措施保护您的数据安全：

  • 敏感信息加密存储：身份证号码在数据库中加密存储，即使数据库备份泄露也无法解密；界面中仅显示后4位
  • 传输加密：所有数据传输均使用 HTTPS 加密
  • 权限控制：只有登录用户才能访问数据，且房东之间数据互相隔离；查看完整身份证号码需经过身份权限校验
  • 文件保护：合同照片、文件的上传和访问均需登录校验

五、第三方服务与信息共享

系统坚持"最少必要"原则。为完成特定功能，部分数据会发送给下列第三方服务提供方。我们逐项说明共享给谁、共享什么、用来做什么、是否必需、如何关闭，除此之外不向任何第三方共享、出售您的数据：

  • ① 邮件推送（可选）
    共享给：电子邮件投递服务（仅用于把邮件送到您填写的邮箱）。
    共享内容：提醒所必需的最少信息，仅含租客姓名、房号、金额、日期，不含身份证号、完整手机号等敏感信息。
    用途：向您本人发送缴费、合同到期、生日等提醒。
    启用与撤回：默认不发送。仅当您在"设置"中主动填写通知邮箱后才启用；您可随时清空邮箱或关闭"启用提醒"开关停止发送。
  • ② 微信推送 PushPlus（可选）
    共享给：PushPlus 推送服务（pushplus.plus）。
    共享内容：同上，仅含提醒必需的最少信息，不含身份证号等敏感信息。
    用途：把缴费、合同到期、生日等提醒推送到您本人微信。
    启用与撤回：默认不发送。仅当您在"设置"中主动填入并保存自己的 PushPlus Token 后才启用；您可随时清空 Token 或关闭"启用提醒"开关停止推送。
  • ③ 高德地图（地图定位功能）
    共享给：高德开放平台。
    共享内容：仅您在登记楼栋/房源时输入的地址文字或地点搜索关键词，用于地理编码和在地图上标注位置；不向其发送租客姓名、手机号、身份证号、租金等任何租户个人或账务信息。
    用途：把地址转换为地图坐标、辅助地点搜索。
    是否必需：仅在您使用地图定位相关操作时触发，不使用该功能则不会调用。
  • ④ 静态资源与组件 CDN（加载页面所需）
    共享给：提供前端组件库、Excel 导出组件、网络时间校准的公共 CDN。
    共享内容：您的浏览器在加载页面脚本/组件时会向这些 CDN 发起请求（如同访问任何网站一样，对方可能记录访问 IP 等标准日志），系统不通过 CDN 传输任何业务数据或租户信息。
    用途：保障页面正常打开、表格渲染、Excel 导出等基础功能。

我们不会做的事：我们不会向任何第三方出售、出租您或您租户的数据；不会将数据用于本声明所述用途之外的商业推广；不会把身份证号、完整手机号等敏感信息提供给上述提醒或地图服务。

法定披露：仅在公安机关、司法机关等国家机关依据生效法律文书依法要求时，我们才会在法律规定的最小范围内配合提供。

六、您的同意与撤回

系统中的信息外发均以您的主动配置为前提，您始终拥有选择权：

  • 同意方式：邮件与微信提醒均为"默认关闭、由您主动填写邮箱或 PushPlus Token 后开启"，您的填写与保存即视为对该提醒渠道的单独同意。
  • 随时撤回：您可在"设置"中随时关闭"启用提醒"总开关、清空通知邮箱或 PushPlus Token，撤回立即生效，撤回后不再产生任何对外推送。
  • 撤回不影响：撤回推送授权不影响系统的核心记账、房源与租客管理、数据本地存储等功能，也不影响撤回前基于您同意已发送的提醒。
  • 政策更新：如新增第三方共享情形，我们会先更新本声明并在系统内提示，涉及敏感信息的新共享将再次取得您的同意。

七、您的权利

您对自己的数据拥有以下权利：

  • 访问权：您可以随时登录系统查看您的所有数据
  • 修改权：您可以修改租户信息、合同信息等
  • 删除权：您可以删除租户记录、合同文件等任何数据
  • 导出权：您可以通过"导出Excel"功能将所有数据导出到本地
  • 注销权：您可以联系我们删除您的账户和所有数据

八、数据保留期限

您的数据将在以下情况下保留：

  • 账户活跃期间：持续保留
  • 账户注销后：您可以要求我们删除所有数据
  • 浏览器本地缓存：系统会在您的浏览器中自动保存备份缓存，您可以手动清除

九、未成年人保护

本系统用于房屋租赁管理，租住人员应为年满18周岁的成年人。如果您发现系统中存在未成年人的个人信息，请联系我们删除。
